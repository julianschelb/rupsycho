# Examples

Notebooks in [`examples/`](https://github.com/julianschelb/rupsycho/tree/main/examples):

| Notebook                                                                                         | Shows                                     |
| ------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| [Basics](https://github.com/julianschelb/rupsycho/blob/main/examples/Basics.ipynb)               | Load, run and export an experiment        |
| [Callbacks](https://github.com/julianschelb/rupsycho/blob/main/examples/Callbacks.ipynb)         | Stream answers while the experiment runs  |
| [Parsers](https://github.com/julianschelb/rupsycho/blob/main/examples/Parsers.ipynb)             | Cleaners, validators and judges           |
| [Postprocessing](https://github.com/julianschelb/rupsycho/blob/main/examples/Postprocessing.ipynb) | End-to-end postprocessing pipeline     |

Ready-made configurations in
[`examples/data/`](https://github.com/julianschelb/rupsycho/tree/main/examples/data):

| File                            | Questionnaire                                  |
| ------------------------------- | ---------------------------------------------- |
| `bfi_demo_config.json`          | Big Five Inventory (demo, two personas)        |
| `bfi_small_and_mid.json`        | Big Five Inventory with small and mid-size models |
| `bdi_qwen72.json`               | Beck Depression Inventory                      |
| `trolley_qwen72.json`           | Trolley problem                                |
| `gsdb_new_qwen.json`            | Gender/sex-related questionnaire               |
| `rfq_*_small.json`              | Reflective Functioning Questionnaire, three prompt formats |
| `example_config_for_demographics_judge.json` | Demographics judge                |

The materials from the user study are in `examples/user_testing/`.
